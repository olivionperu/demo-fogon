# El Fogón — Web demo (portfolio OLIVION)

Sitio de demostración para el portfolio de OLIVION. Negocio ficticio (restaurante) usado para mostrar capacidad a prospectos reales.

## Contenido
- `index.html` — Home
- `servicios.html` — Servicios
- `nosotros.html` — Nosotros
- `contacto.html` — Contacto (formulario + WhatsApp + mapa)
- `css/style.css`, `js/script.js`

## Pendiente al desplegar
- Reemplazar el número de WhatsApp de ejemplo (+51 999 999 999) en todas las páginas si se usa como demo en vivo con contacto real.
- Actualizar las URLs de `sitemap.xml` con el dominio real una vez desplegado.
- Las fotos son placeholders de picsum.photos — reemplazar por fotos reales al usar con un cliente real.
- El formulario de contacto abre WhatsApp con el mensaje prellenado (no envía a un servidor — no hay backend en esta demo).
